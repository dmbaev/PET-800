# PET-800

**Хромированный T-800 для ChatGPT / Codex Desktop**

<img src="assets/preview.gif" alt="PET-800 машет рукой" width="192">

Миниатюрный эндоскелет с красными оптическими сенсорами. Реагирует на работу, ожидание, ошибки и завершение задач.

## Возможности

- 9 анимаций: покой, бег вправо и влево, приветствие, прыжок, ошибка, ожидание, работа и просмотр результата.
- 16 направлений взгляда с поворотом металлической головы.
- Прозрачный атлас v2: **1536 × 2288**, ячейка **192 × 208**.

## Установка и запуск

1. [Скачайте PET-800.zip](https://github.com/dmbaev/PET-800/releases/latest/download/PET-800.zip) и распакуйте архив. Внутри находится папка `t-800`.
2. Скопируйте **всю папку** `t-800` в каталог питомцев:
   - **Windows:** `%USERPROFILE%\.codex\pets\t-800\`
   - **macOS / Linux:** `~/.codex/pets/t-800/`
3. Проверьте, что в конечной папке лежат `pet.json` и `spritesheet.webp` (а не ещё одна вложенная папка `t-800`).
4. Откройте настольное приложение ChatGPT / Codex. В меню профиля выберите **Settings → Pets**, нажмите **Refresh** и выберите **T-800**.
5. Введите `/pet` в поле команд приложения или выберите **Show pet** в меню команд: питомец появится поверх рабочего стола. Повторная команда `/pet` скрывает его.

Если **T-800** не появился в списке, проверьте путь к файлам из шага 3 и повторно нажмите **Refresh**. Файлы также лежат в корне репозитория для просмотра и повторной упаковки.

## Совместимость

Этот пакет предназначен для настольного приложения ChatGPT / Codex. [Официальная документация о питомцах](https://learn.chatgpt.com/docs/pets) описывает выбор локального питомца через **Settings → Pets**. Веб-загрузка пользовательского атласа сейчас требует размер 1536 × 1872; у PET-800 формат v2 1536 × 2288.

Неофициальный фанатский проект. Не связан с правообладателями Terminator.
